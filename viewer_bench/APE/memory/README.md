# Memory — persistent habitat memory

This folder is the **living memory of this habitat** (one FEM project).
It grows over sessions. Do not put cross-project playbook rules here —
those belong in `APE/instructions/` and must stay **generic** across
mechanics domains.

| File | Purpose |
|------|---------|
| `brief.md` | Intent, members, done-when, agent intake for *this* model |
| `assumptions.md` | Active modeling assumptions |
| `decisions.md` | Dated decision log (why, not only what) |

Optional later: `open-questions.md`, `session-notes/`, `lessons.md`.

**Rule:** if it must still be true next week for *this* project, write it here.
