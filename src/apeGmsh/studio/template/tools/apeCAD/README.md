# apeCAD — habitat tool door

Open::

```text
python tools/apeCAD/open_interface.py
python tools/apeCAD/open_interface.py --role agentic
```

| Folder | Purpose |
|--------|---------|
| `human_sketches/` | Human CAD documents, screenshots, confirm schemes |
| `agentic_sketches/` | Agent-authored spatial drafts for Socratic review |

Prefer saving `.json` documents (and any stills) into the role folder for
the current session. See `tools/README.md`.
