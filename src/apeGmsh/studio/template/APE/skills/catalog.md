# Agent skills catalog

Empty until you run:

```text
python APE/skills/harvest.py
```

This scans `<github>/` (your `~/Documents/Github/`) and `~/.claude/skills`
for `SKILL.md` files and rewrites this file + `catalog.json` from what it
finds on **your** machine. No skill catalog ships with this template — see
`APE/skills/README.md` for why and for agent guidance.
