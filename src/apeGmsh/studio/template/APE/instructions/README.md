# Instructions — how we work (template)

Cross-project playbook for **APE Studio** habitats in **FEM mechanics**
(wide generality). Copy with the APE tree. Change these files when the
*general* way of working changes — not when one model’s gap, record set,
or constitutive parameters change (those go in `APE/memory/`).

| File | Purpose |
|------|---------|
| `how-we-work.md` | Session contract, folder roles, agent hygiene, template scope |
| `socratic-geometry.md` | Human ↔ agent dialogue for geometry **and** physics (gates) |
| `progressive-modeling.md` | Oracles, stage metrics, escalated complexity (incl. apeSees bridge) |
| `session-postmortem.md` | End-of-session metrics + friction → backlog / upstream |
| `continuous-improvement.md` | Full improvement map (beyond skills/libraries) |
| `analysis-profiling.md` | FEM stack profiler (`profile.h5`) + link to agent token sidecar |
| `reporting.md` | **Locked** — briefs / ledgers / per-stage model reports |
| `studio-mcp.md` | Habitat MCP tools; lookup-first; server id |

Optional later: `naming.md` — keep this folder small and authoritative.
