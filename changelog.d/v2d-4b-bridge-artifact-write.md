### ADDED — the bridge writes `model.h5` automatically (ADR 0112 D1 for `apeSees`; program slice V2d-4b, #1307, #1451)

A run that uses `apeSees` and never calls `ops.h5(path)` now leaves the full `model.h5` (neutral zone, `/opensees`, `/provenance`, this run's `session_id`) at the session's conventional path, `<artifact dir>/<model_name>.h5`, beside the `<model_name>.geometry.h5` sibling the session writes. The write runs at the end of every terminal deck emit (`tcl`, `py`, `modal_deck`) and live build (`run`, `analyze`, `eigen`, `modal_properties`, `eigen_feast`, `complex_eigen`, `modal_response_history`, `response_spectrum_analysis`, the FRF sweeps, `critical_time_step`, `analyze_explicit`), through the D1 overwrite policy (P1–P4) and two rules of its own, in the new module `apeGmsh.opensees._internal.artifact_write`: a loop of emits on one model writes once and writes again only when a primitive, a record (a `fix`, `mass`, `region`, `stage`, ...) or the snapshot changed (P5); `apeSees(fem, _artifacts=False)` opts a library-internal bridge out (P6: the ETABS and STKO importers, `strut_tie` and the emit-cost bench pass it). An explicit `ops.h5(path)` is unchanged (P7). The write never raises into the run: a snapshot with no name (a session with no `model_name=` run from a notebook, `-c`, stdin or a console-script launcher; a `from_msh`, import or compose snapshot), a partitioned snapshot, a target the policy refuses, or a failed write warns once per bridge (`BridgeArtifactWarning`) and writes nothing; an MPI rank other than 0 is silent. The session's no-name warning now names console-script launchers too, and the emit-cost bench gains a case that reports the write's cost by itself.
