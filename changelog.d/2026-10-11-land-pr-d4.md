### CHANGED — `scripts/land_pr.py` runs origin/main's rules, refuses Accepted flips and unlabelled freeze-baseline edits, and lets a freeze's holder land (ADR 0121 D4, #1686)

`land_pr.py` now runs origin/main's copy of itself, never the checkout's (maintainer ruling 2 on #1686). `main` fetches origin/main, writes `git show origin/main:scripts/land_pr.py` to a temp file and runs it. An environment marker that names that file's own path stops the re-exec. As a result, a PR that edits `land_pr.py` is judged by the rules it would replace, and such an edit needs no `human-gate`. `--dry-run` and `--verify-only` pass through unchanged.

Checks 7 and 8 implement ADR 0121 invariant 8. Both read the PR files listing (`gh api --paginate .../pulls/N/files`).

- **Check 7** refuses a diff that sets an ADR's Status to Accepted, through any of three routes:
  - an existing ADR's header Status line flips to Accepted;
  - a new ADR file is born Accepted;
  - a file is renamed into a new ADR number with an Accepted header, either from a non-ADR file or from another ADR number.

  For a born file it judges the whole header of the head's copy. It reads the Status the way `scripts/adr_index.py::parse_adr` does, and a test pins that agreement over every ADR on disk. If GitHub returns no patch for a modified ADR, the check refuses. No label lifts check 7.
- **Check 8** refuses an edit to the census baseline (`tests/freeze_census.py` or `tests/test_freeze_lock.py`) when the PR lacks the `human-gate` label. A rename away from either file counts as an edit.

The maintainer's web merge stays the exception path for both checks.

Check 5, the `freeze:<file>` window, now exempts the PR that holds the freeze. A PR holds it if it carries the label itself, or names an issue that carries it, either as `Slice: #<n>` or through a closing keyword. Before this change, #1702 could not land under its own freeze.

`run_gh` and `run_git` now decode their output as UTF-8, not with the locale codec.

The replays use the recorded patches of #1512 (Proposed to Accepted) and #1522 (born Accepted).
