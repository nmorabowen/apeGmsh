### CHANGED — `scripts/land_pr.py` refuses Accepted flips and unlabelled freeze-baseline edits, and lets a freeze's holder land (ADR 0121 D4, #1686)

`land_pr.py` gains checks 7 and 8, which are ADR 0121 invariant 8. Both read the PR files listing (`gh api --paginate .../pulls/N/files`). Check 7 refuses a diff that sets an ADR's Status to Accepted. That covers an existing ADR whose header Status line flips to Accepted and a new ADR file born Accepted. It reads the Status the way `scripts/adr_index.py::parse_adr` does, and a test pins that agreement over every ADR on disk. If GitHub returns no patch for an ADR, the check refuses. No label lifts check 7. Check 8 refuses an edit to the census baseline, `tests/freeze_census.py` or `tests/test_freeze_lock.py`, when the PR lacks the `human-gate` label. A rename away from either file counts as an edit. The maintainer's web merge stays the exception path for both checks. Check 5, the `freeze:<file>` window, now exempts the PR that holds the freeze: one that carries the label itself, or one that names an issue carrying it as `Slice: #<n>` or with a closing keyword. Before this, a split PR could not land under its own freeze (#1702). The replays use the recorded patches of #1512 (Proposed to Accepted) and #1522 (born Accepted).
