### ADDED — `scripts/land_pr.py`, the landing gate, with a replay test (program slice A2.2, #1222)

`python scripts/land_pr.py <n> [--dry-run]` is the one door through which a PR reaches `main`. It runs the AGENTS.md "How work lands" checklist as code, in order, refusing on the first failure with a message that names the check and the lesson: the base is `main`; the PR is open, not a draft and not already merged; the local `HEAD` equals `headRefOid`; the tree is clean; no changed file is inside an open `freeze:<file>` label; the PR is not conflicting and the five required checks are green on the head SHA, with pending a refusal rather than a wait. It then squash-merges (never `--auto`, never `--delete-branch`), polls `compare/main...<squash sha>` until it reads `behind` or `identical` (bounded; `diverged` fails naming #858), and fails loudly if the branch tip moved past the merged head (#1097; `headRefOid` freezes at the merge, so it reads `git ls-remote`). GitHub goes through one `run_gh` seam and the checkout through one `run_git` seam, so `tests/test_land_pr.py` replays recorded responses with neither `gh` nor a network: #858 and #1057 are refused at check 1, #1097 is flagged after its merge, #1218 lands clean, and each check has a refusal case. AGENTS.md "How work lands" and PROGRAM.md §4 now point at the script.
