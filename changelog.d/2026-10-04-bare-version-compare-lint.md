### CHANGED — a quirk-lint rule flags a version compared against a bare tuple literal; the dead pre-2.7 ndf branch is gone (#1303)

`scripts/check_quirks.py` gains `bare-version-compare` (ADR 0113 INV-8): in `src/apeGmsh`, a file or zone version compared against a tuple of two or three integer literals (`_fv < (2, 7, 0)`), or against a `SchemaVersion(...)` / `parse_version("...")` built inline from literals, is a finding. A compare against a named `*_FROM` / `*_FLOOR` constant passes, as does `sys.version_info`. The self-test runs the rule on the pre-change `_femdata_h5_io.py`, on `read_spatial_ndm` with its constant inlined, and on the named form. The one site it found, the `_fv < (2, 7, 0)` branch in `FEMData.from_h5` that synthesised an all-sentinel `/nodes/ndf` for pre-2.7 files, is deleted: the neutral floor is 2.10.0, `validate_zone_version` refuses an older file before that code runs, so the branch could not execute and a missing `/nodes/ndf` always reads as `None`. No file that opened before is refused.
