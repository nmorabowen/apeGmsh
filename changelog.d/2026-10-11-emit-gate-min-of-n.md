### Emit-cost gate: min-of-7 estimator, baseline rewritten on the CI runner (#1658)

`test_emit_regression_gate.py` now takes the minimum of 7 repeats of emit and of parse, separately, instead of the median of 3. Timing noise on a shared runner only ever slows a rep down, and on CI `parse` is still warming up for the first ~4 reps, so the median of 3 swung the same commit across the 1.7x ceiling (hex 0.716 then 0.627). `emit_gate_baseline.json` is rewritten on the GitHub runner with the new estimator and carries a `_provenance` block naming the run. The previous file was written on Windows in July (639a5a11), about 1.2x below CI, and has since absorbed intended emit work (ADR 0100 P3, ADR 0099, K1-3d S3c). `deck_lines` and the 1.7x tolerance are unchanged. Dispatching the Tests workflow with `write_emit_gate_baseline` regenerates the file on the runner and uploads it as the `emit-gate-baseline` artifact.
