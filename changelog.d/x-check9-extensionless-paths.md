### FIXED — land_pr check 9 reads extensionless file names in an Owned list

Check 9 dropped every backticked Owned name with neither `/` nor `.`, so a card that owns `FORK_PIN` or `LICENSE` could never pass it: card #1929's only Owned file was `FORK_PIN`, check 9 refused #1930 as naming no path, and it needed `scope-ok` (#1939). Such a name now counts when it opens its list item (a bullet that starts with `FORK_PIN`; trailing prose is fine) and is already a file on `origin/main` (`git ls-tree -r`, case-sensitive). The same name inside parenthetical prose or mid-line, a word that names no file (`foo`, `suite`, `-`), an extensionless glob, and a file the PR itself adds all own nothing; a card that creates an extensionless file still needs `scope-ok`. A failed or empty read of `origin/main` refuses rather than admits. Negation handling is unchanged.
