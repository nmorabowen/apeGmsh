### FIXED — land_pr check 9 reads extensionless file names in an Owned list

Check 9 dropped every backticked Owned name with neither `/` nor `.`, so a card that owns `FORK_PIN`, `LICENSE` or a new `Makefile` could never pass it: card #1929's only Owned file was `FORK_PIN`, check 9 refused #1930 as naming no path, and it needed `scope-ok` (#1939). Such a name now counts when it is a real file, either one the PR changes or one `git ls-tree -r origin/main` lists, matched case-sensitively and as a sibling when it follows a path in a list. Words that name no file (`foo`, `and`, `lock-tests`, `-`) and extensionless globs still own nothing. A failed or empty read of `origin/main` refuses rather than admits. Negation handling is unchanged: an Owned line that negates still refuses, and an amendment bullet such as "Do not touch `FORK_PIN`" still excludes the list after it. A replay of 383 program cards and 57 amendments differs from main's parse only on #1929 and #1497, each of which now owns `FORK_PIN`.
