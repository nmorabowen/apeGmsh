### ADDED — apeGmshViewer P0 spike: open a model.h5 without apeGmsh (ADR 0112, program slice V1a, #1285)

`apeGmshViewer/` is a new TypeScript + three.js app in an Electron shell that opens a `model.h5` with h5wasm, with no apeGmsh import and no Python. It draws the mesh coloured by physical group (solids show their boundary faces, see-through when line elements sit inside them) and, on a click, fills an inspector with the element's definition chain: element → geomTransf → beamIntegration → section → materials. Every value names the HDF5 path it came from, and the links that needed OpenSees command syntax to follow (bare tags in positional `args` / `params`) are marked *interpreted*; a type outside the syntax table, a tag that matches no object or two, and a dangling `material_ref` are reported by name. Navigation follows the CAD convention: the camera stays Z-up, a right-drag orbits as a turntable about the mesh point under the cursor, a middle-drag or shift + right-drag pans, the wheel zooms toward the cursor, `F` fits the model, and a left-click selects. State lives in one store with one-way data flow (ADR 0112 D6). `npm run measure` prints a row of the new measurement ledger `apeGmshViewer/MEASUREMENTS.md` (file size, nodes, elements, time to first frame, median orbit fps, memory, inspector fill time), and `npm run capture` writes stills from a hidden window. The ledger records the P0 kill-criteria verdict and the HDF5 path behind every inspector field. A small beam fixture made by `examples/shoebuckle_arch.py` backs the tests, whose expected values are closed forms of the example's parameters.
