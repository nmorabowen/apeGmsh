### CHANGED — reference scripts and the read-results guide use the R2 read-back API (ADR 0115, R2-d #1730)

The skill's `pratt_truss.py` reads bar forces with `ops.elements.get(pg=...).read("axial_force")` and the midspan deflection with `ops.nodes.one(label=...).read("displacement_y")`, so the recorders, the `ops_raw.wipe()` flush and the `raw-ops:` line are gone. `frame_modal.py` reads each floor master with `ops.nodes.one(label=...).read("displacement_x")`, which removes the `[master] = ops.nodes.get(...)` one-node workaround and its raw `nodeDisp` call. Both hand checks agree within their unchanged tolerances. The `raw-ops:` count in the reference scripts goes from 2 to 0 and the `API gap` markers from 9 to 6. The how-to "Read a node's displacement and reactions" gains a section on the live `.read`, `label=`, `ops.results(path)` with `.item()`, and the `<deck>.run.tcl` driver.
