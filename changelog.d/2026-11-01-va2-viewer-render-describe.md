### ADDED — apeGmshViewer: view specs, `--render` and `--describe` (ADR 0128 slice 2, #2651)

`apeGmshViewer` takes stills headlessly from a view spec, `apegmsh-view/1`: a JSON document that names the files, the still size, the theme and a list of shots (stage, step, camera, colouring, contour, deformed shape, section planes, isolated groups). `node scripts/launch.mjs render <spec.json> <outdir>` opens a hidden window, takes every shot, writes `<name>.png` per shot and `render.json` into `<outdir>`, and exits; it takes no single-instance lock, so it runs beside an open window and never changes it. `node scripts/launch.mjs describe <file.h5> <outdir>` writes `describe.json`: the set's stages, steps and times, fields and components, physical groups, bounding box and the spec's accepted values. The spec fails closed. An unknown key, a wrong type or an unknown version refuses the whole spec, names the key and writes no PNG (exit 2). A shot that names a stage, step, field, component or group the files do not have, or a view the app itself refuses (a deformed shape the banner refuses, an element field that does not join the mesh, a whole-history range that could not be read), is refused with that reason and writes no PNG, while the other shots still run (exit 1). Version 1 refuses `camera: "fit-selection"`, since a spec cannot make a selection; every still it draws is pixel-identical between runs. The out folder must be absent or empty (otherwise exit 2, nothing written), and Chromium's profile is kept in `<outdir>/.chromium`, so a run writes nothing outside its folder. Batch stills default to the light theme. A shot also chooses its capture layers (ADR 0128 D9): in `chrome: "app"` it can omit named panels (`header`, `phase`, `viewcube`, `left_rail`, `rail`, `windows`, `banner`) from the layout, and in `chrome: "model"` the still is the viewport alone at the spec's size, with a scale bar (on by default for a contour), an axes triad, the banner text and the caption drawn into the image, on the theme's background or on transparent pixels (`background: "transparent"`).
