### ADDED — apeGmshViewer reads layered-shell results from a `.ladruno` (crack plots, slice 1)

The viewer's `.ladruno` reader now reads `section.fiber.<token>` buckets on layered shells (ASDShellQ4 / ASDShellT3 with a LayeredShell section): crack vectors (`crackPattern`), damage, layer stress and strain. These buckets were listed as unread before. Each header bucket becomes a layer group, with one value per element, Gauss point, responding layer and component. The responding layers are those whose material answers the token; rebar layers do not, and the recorder writes them as zero-width blocks. Layers are in section order, the first on the shell's −e3 side. Each layer's through-thickness position and thickness, and each element's section thickness, come from `MODEL/SECTION_ASSIGNMENTS`. A section that does not cover the column map's layers leaves the geometry absent and gives the reason. A bucket that disagrees with itself is refused by name. Shell frames come from `MODEL/LOCAL_AXES`, which the fork writes for shells from nmorabowen/OpenSees#1133. Layer groups of a partitioned set are listed as unread, as its Gauss groups already are. Nothing draws layer results yet: the Cracks card's shell section is the next slice. New fixture: `ladruno_shells3d` (a fork run of a cracked layered wall, `make_ladruno_fixtures.py --shells`).
