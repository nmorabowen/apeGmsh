### FIXED — apeGmshViewer's D7 capture (`--mode=capture`) writes no still once the run is ending, and no partial PNG (VA2l, #2736)

The `capture:still` handler wrote with a plain `writeFileSync` and never checked whether the run was ending. If the hang watchdog, a crash or an uncaught error called `headlessEnd` while a capture was settling, a still could be written beside `<out>.error.txt`, and a write that threw part way (a full disk) left a partial PNG. The handler now goes through `refuseIfEnding` and `writeStill`, as `render:capture` does since VA2h (#2708), and both handlers take their still from one settle helper. `test/spec/capture-still.e2e.ts` forces the run to end inside the capture that settles the first still, and forces a partial write of it; each leaves no PNG and exits 1.
