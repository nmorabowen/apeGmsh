### CHANGED — `opensees/_internal/build.py` is now the `build/` package (internal, pure move; program slice S2-a, #1696)

The 12,447-line `opensees/_internal/build.py` is split into `opensees/_internal/build/`: 17 modules plus a `validators/` sub-package (mesh, up, solver, loads, materials), none over 1,500 lines. No function or class body changed and no emitted deck changed (the 86 golden decks are byte-identical). There is no facade: `build/__init__.py` holds only a docstring and `__all__` is gone, so every importer in `src/` and `tests/` imports a name from its defining submodule. `_stacklevel_outside_package` moves to `_internal/_stacklevel.py` rather than into `build/`, because its body counts `dirname` hops from `__file__` and a deeper file would change the answer. `_internal` is private; nothing user-facing changes.
