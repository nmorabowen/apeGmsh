### ADDED — apeGmshViewer stitches layered-shell results across a partitioned `.ladruno` set (crack plots, slice 1b)

An OpenSeesMP run writes one `.ladruno` per rank, and the viewer used to list every element result of such a set as unread. Layer groups (layered-shell `section.fiber.*` results) are now stitched. Each element lives on one rank, so a group is the rows of the parts that hold it, end to end in part order. A rank may hold none of a group: here a header bucket of one section type sits on one rank only. The parts must agree on a group's Gauss points, layers, components and natural coordinates; a disagreement, or a part that refuses the group, refuses the stitched group and names the part. An element found in the layer buckets of two parts refuses the set at open (#2316). The set's element-id verdict is now verified when every part is stamped `element_index_space = "fem"`; before, a set was always unverified. Gauss and line-station results of a set stay unread. New fixture: `ladruno_shellparts`, a 2-rank OpenSeesMP run (`make_ladruno_fixtures.py --shellparts`).
