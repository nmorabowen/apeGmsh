### INTERNALS — MPM lattice seeding and the Contract-1 particle-set writer, not yet wired to an emitter (#2980)

ADR 0134 D1, D2 and D6 start in the internal bridge package `apeGmsh.opensees._mpm`. `seed_lattice` places `n` particles per grid cell per axis at the sub-cell centres and keeps those inside an element of each body's physical group, read from FEMData alone: barycentric coordinates for `tri3` and `tet4`, the inverse isoparametric map for `quad4` and `hex8`. A point on a shared face is kept once. Other element families, inverted elements, overlapping bodies and empty bodies are refused by name. The writer produces the fork's Contract-1 file (`ladruno-mpm-particles`, version 1) through a temporary file, and replaces an existing file only when an apeGmsh emit wrote it. Re-seeding the fork's fixture model reproduces `particle_set_v1.h5`, and every seeded file passes the fork's own validator. The deck emitters call none of this until the `mpm` family lands (M3); there is no public API change.
