### ADDED — apeGmshViewer's materials window runs and plots a uniaxial material on the Ladruno fork

The Materials & sections window gains a **Test** button on each uniaxial material (ADR 0135
Amendment 1). It opens a form for a monotonic, cyclic or pasted strain history; **Run** has the
installed fork run the declared material with its dependencies, and the window draws the response
curve with the fork's build id, or the solver's message when the run fails. Bond-slip and cohesive
hinges get their own axis names. The screen lives in the window until ADR 0137's tool host exists.
