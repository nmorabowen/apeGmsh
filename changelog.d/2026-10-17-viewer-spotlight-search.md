### ADDED — Spotlight (`Ctrl+K`) command palette, pure Search Engine, and Search Window in `apeGmshViewer` (ADR 0112)

`apeGmshViewer` now provides a macOS/apeWorkbench-style Spotlight command and search palette (`Ctrl+K` / `Cmd+K`) backed by a pure declaration Search Engine (`src/state/search.ts`) and an interactive Search Window (`"search"` in `WINDOW_KINDS`). Spotlight exposes all viewer actions through a compile-time exhaustive `SPOTLIGHT_EVENT_LEDGER` over `EventType`, supports boolean and natural-language declaration queries (`and`, `or`, `not`, sub-token pattern matching, transitive `uses:` over sections/integrations/materials, numeric parameter comparisons, and `Tab` filter chips), batch visibility/selection actions via `Shift+Enter` (`Hide`, `Show`, `Isolate`, `Select & Frame`, `Add to Selection`), multi-step `set` drill-downs for viewer properties, and an interactive `? Help` guide.
